## 为什么三语言提取器更快？

### LLM 提取（慢）

```
文档 → LLM API 请求 → 等待响应 (8-15秒) → 解析结果 → 保存
        ↑
     网络延迟 + API 处理时间 + 排队时间
```

**瓶颈**:
- 网络往返时间 (RTT): ~100-300ms
- LLM 推理时间: ~5-10 秒
- API 速率限制: 每分钟请求数限制
- 排队等待: 高峰期延迟

### 三语言提取器（快）

```
文档 → 本地模型推理 (0.5-1.5秒) → 解析结果 → 保存
        ↑
     无网络延迟 + GPU/CPU 直接处理
```

**优势**:
- 无网络延迟: 本地处理
- 批量优化: spaCy/HanLP 支持批处理
- 无速率限制: 本地模型无限制
- 专门优化: 针对特定语言的高性能模型

## 配置三语言提取器

### 方法 1: 通过环境变量

编辑 `.env` 文件：

```bash
# 启用三语言实体提取器
TRILINGUAL_ENABLED=true

# 默认使用三语言提取器
USE_TRILINGUAL_BY_DEFAULT=true
```

### 方法 2: 通过配置文件

编辑 `config/local.yaml`:

```yaml
trilingual:
  enabled: true
  default_language: zh

lightrag:
  entity_extraction:
    use_trilingual: true  # 默认使用三语言提取器
    fallback_to_llm: true  # 如果三语言提取失败，回退到 LLM
```

### 方法 3: 运行时指定

在 API 请求中指定：

```python
requests.post(
    "http://localhost:9621/insert",
    json={
        "text": "你的文档",
        "language": "zh",
        "use_trilingual": True  # 使用三语言提取器
    }
)
```

## 性能优化建议

### 1. 批量插入

**不推荐**（逐个插入）:
```python
for doc in documents:
    requests.post("/insert", json={"text": doc})
```

**推荐**（批量插入）:
```python
requests.post("/batch_insert", json={
    "documents": [{"text": doc} for doc in documents]
})
```

### 2. 并发请求

```python
from concurrent.futures import ThreadPoolExecutor

with ThreadPoolExecutor(max_workers=4) as executor:
    futures = [
        executor.submit(insert_document, doc)
        for doc in documents
    ]
```

### 3. 使用 GPU 加速

安装 GPU 版本的 spaCy:
```bash
pip install spacy[cuda12x]  # CUDA 12.x
```

在 Python 中启用 GPU:
```python
import spacy
spacy.prefer_gpu()
```

### 4. 增加批处理大小

编辑配置:
```yaml
trilingual:
  english:
    batch_size: 64  # 默认 32
  swedish:
    batch_size: 64
```

## 故障排除

### 问题 1: 速度提升不明显

**可能原因**:
- 三语言提取器未正确启用
- 模型未加载到内存
- 仍在使用 LLM 提取

**解决方法**:
```bash
# 检查配置
curl http://localhost:9621/config

# 应该看到:
# "trilingual_enabled": true
# "use_trilingual_by_default": true
```

### 问题 2: 首次请求很慢

**原因**: 模型懒加载，首次使用时需要加载到内存（~2-3 秒）

**解决方法**: 预热模型
```bash
# 发送预热请求
curl -X POST http://localhost:9621/extract \
  -d '{"text":"test","language":"zh"}'
```

### 问题 3: 内存不足

**症状**: OOMKilled 或 MemoryError

**解决方法**:
- 使用更小的模型（en_core_web_sm, sv_core_news_sm）
- 减少批处理大小
- 增加系统内存或交换空间
